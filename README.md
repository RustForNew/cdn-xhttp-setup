# CDN XHTTP Setup

Программа для настройки **VLESS XHTTP TLS через готовый CDN**. Запускается на домашнем компьютере с Windows или Linux, подключается к VPS по SSH и выполняет установку. В конце вы получаете ссылки для подключения — отдельную для каждого пользователя.

Можно использовать один VPS или добавить второй сервер для выхода в интернет. CDN-ресурс и DNS-записи нужно подготовить заранее.

## Что понадобится

- **Python 3.10 или новее** на вашем компьютере. [Скачать Python](https://www.python.org/downloads/). В установщике Windows отметьте **Add Python to PATH**.
- **VPS с Ubuntu 22.04 или 24.04**, доступ по SSH через root или пользователя с sudo. Используйте сервер без других сайтов и панелей на портах 80/443.
- **Домен сервера-источника (origin)**, например `origin.example.com`. Его A-запись должна указывать на IP вашего VPS.
- **Готовый CDN с собственным доменом**, например `cdn.example.com`, настроенным CNAME и выпущенным HTTPS-сертификатом.

На VPS должны быть доступны SSH, TCP 80 и 443. В CDN укажите HTTPS к origin, Host/SNI origin-домена, разрешите GET/HEAD/OPTIONS и отключите кеширование. [Подробная настройка CDN](docs/operations.md#настройки-существующего-cdn).

## Как запустить

**1. Скачайте проект:** нажмите **Code → Download ZIP** и распакуйте архив.

**2. Откройте терминал в распакованной папке.**

Windows — командная строка CMD:

```bat
run.cmd
```

Linux:

```bash
bash run.sh
```

При первом запуске нужен интернет: программа подготовит окружение и установит зависимости в свою папку. При следующих запусках повторная установка не нужна, если версия программы и зависимости не изменились. Если Linux сообщает об отсутствии `venv`, установите пакет `python3-venv`.

**3. Пройдите мастер настройки:**

- Сначала выберите мост: **N** — один VPS, **Y** — входной и отдельный выходной VPS.
- Введите IP, SSH-логин, порт, пароль и домен каждого сервера.
- Укажите CDN-домен, email для выпуска сертификата, название подключения и количество ссылок.
- Проверьте сводку и ответьте **Y**, чтобы начать установку.

В вопросах Y/N подходят и строчные `y`/`n`. Если допущена опечатка, программа повторит вопрос. Параметры XHTTP выбираются автоматически.

При первом подключении сверьте показанный отпечаток SSH-ключа с данными в консоли VPS. Пароль вводится скрыто и не записывается в файлы.

**4. Заберите ссылки из `result/vless.txt`.** Каждая строка — отдельная ссылка со своим UUID. Импортируйте её в клиент с поддержкой VLESS, XHTTP и параметра `extra`.

Если клиент потерял настройки при импорте, перенесите содержимое `result/xhttp-extra.json` в поле **XHTTP extra**. Там должны сохраниться `packet-up`, `OPTIONS` и параметры padding.

## Что делает программа

- Устанавливает Nginx и Xray, получает и настраивает продление сертификата origin.
- Создаёт от 1 до 1000 ссылок с разными UUID и выбранным названием.
- Настраивает прямой выход через один VPS или выход через второй VPS.
- Проверяет HTTPS и передачу данных через CDN, сохраняет резервную копию своих конфигов.

Программа **не создаёт CDN-ресурс и DNS-записи**. Сертификат CDN-домена нужно подключить в панели CDN отдельно. Для второго VPS потребуются ещё его SSH-доступ и домен; [подробнее](docs/operations.md#второй-сервер).

## Повторный запуск

Параметры сохраняются в `deployment.json`. Просто запустите `run.cmd` ещё раз: мастер предложит продолжить установку с прежними UUID, создать новую конфигурацию с резервной копией старой или выйти. SSH-пароли нужно ввести заново.

Для установки с сохранёнными настройками можно сразу выполнить:

```bat
run.cmd deploy
```

Чтобы проверить подключение к origin и CDN:

```bat
run.cmd check
```

В Linux используйте `bash run.sh deploy` и `bash run.sh check`. Проверка CDN не заменяет пробное подключение в вашем VLESS-клиенте.

**Не публикуйте `deployment.json` и папку `result`: они содержат данные доступа.** Пользователю достаточно передать одну назначенную ему ссылку.

## Совместимость

Установщик рассчитан на Ubuntu 22.04/24.04 с systemd, amd64/arm64. Установка проверена на Ubuntu 22.04 и 24.04 amd64. Подробные границы проверки указаны в [документации по тестированию](docs/testing.md#границы-совместимости). Версия Xray закреплена на 26.5.9.

Мастер автоматически применяет настройки отправки с паузой 5 мс и сохраняет OPTIONS и padding. Скорость зависит от сети и CDN.
