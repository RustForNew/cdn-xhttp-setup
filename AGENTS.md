# Работа с проектом

CDN XHTTP Setup — публичный установщик VLESS XHTTP для готового CDN. Перед изменениями читать [docs/index.md](docs/index.md) и релевантные страницы.

Стабильный контракт: Ubuntu 22.04/24.04; готовый CDN; один origin по умолчанию, опциональный exit; OPTIONS→POST и padding сохранены; SSH-пароли и sudo-пароли не записывать в файлы, логи или argv. Не заменять сторонние конфиги Xray/Nginx, не выключать проверку TLS/SSH.

Файлы UTF-8. Изменения архитектуры и эксплуатации отражать в существующих страницах знаний. Документация должна описывать программу для пользователей и разработчиков. Использовать только примерные домены, IP и учётные данные; конфигурации реальных установок не включать в репозиторий. Каждое завершённое изменение сохранять атомарным commit своей области; публикация и развёртывание требуют отдельного поручения. Локальные тесты не заменяют проверку настоящего CDN/VPS.
